My Chord Library

A personal music library and chord-sheet editor for Android and Windows, featuring songlist management, chord transposition, and import/export tools.

Features

  • Organize chord sheets and setlists
  • Transpose chords and edit song sheets
  • Import and export compatible song files
  • Tempo (BPM) lookup integration is being developed

Music data attribution

Tempo lookup is planned using GetSongBPM. Visit GetSongBPM for song tempo and music information.
